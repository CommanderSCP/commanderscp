What the tile refuses to do

  1. No deep links. url is the console base — webUrl else serverUrl, trailing slash trimmed. The schema is explicit that no registry has a known deep-link shape, so linking to the repository path would be fabrication.
  2. No inferred kind. properties.kind is a free string; when it is absent or non-string the schema returns null and the tile says not set on the object. Guessing "harbor" from a name containing "harbor" is the provenance-label mistake.
  3. No winner on ambiguous. More than one publishes_to edge nulls every descriptive field by design. The tile shows edgeCount and stops.
  4. Name is read from the execution-system object, never from the component — the schema says so in as many words.
  5. Both roles are shown. A registry can be a publish target and a webhook source at once (harbor, gitea). Two chips, because a registry that can originate change is a different operational thing from one that only receives.
Nothing here exists on your estate. Zero publishes_to edges, and both execution-systems are kind=argocd. Every tile above is a fixture — including ghcr.io, which is where the image you are running right now comes from.
